# ХАРТИЯ PoCP
## Протокол вклада и распределения долей
**Версия 1.0**

---

# 1. ПРЕДМЕТ ХАРТИИ

Настоящая Хартия определяет:

- создание артефактов;
- фиксацию состояний проекта;
- фиксацию вклада участников;
- распределение долей.

---

# 2. СТРУКТУРА ПРОЕКТА

## 2.1 Объём

**100% долей проекта**

## 2.2 Распределение

- **60%** — командный пул;
- **40%** — резерв (инвесторы / развитие / масштабирование).

---

# 3. СОСТОЯНИЯ ПРОЕКТА

## 3.1 Определение

**Состояние** — это зафиксированный этап готовности продукта, подтверждённый артефактом.

## 3.2 ВАЖНОЕ УТОЧНЕНИЕ (обновлено)

Состояний может быть любое количество.

Минимальная логическая цепочка:

```
S1 → S2 → S3 → S4 → S5 → …
```

> 📌 Состояния не ограничены фиксированным числом.  
> 📌 Они отражают реальную эволюцию продукта.

---

# 4. АРТЕФАКТЫ

## 4.1 Определение

**Артефакт** — это проверяемый результат работы участника.

Примеры:

- код;
- дизайн;
- прототип;
- тест;
- архитектура.

## 4.2 КЛЮЧЕВОЙ ПРИНЦИП

> Каждое состояние существует только через артефакт.

## 4.3 ФИКСАЦИЯ

Каждый артефакт:

- создаётся участником;
- фиксируется в реестре;
- привязывается к состоянию.

## 4.4 ОБЯЗАТЕЛЬНАЯ СТРУКТУРА ЗАПИСИ

- ID артефакта;
- описание результата;
- ссылка на доказательство;
- состояние (S1, S2, …);
- участник-автор;
- вклад других участников (если есть);
- время фиксации.

---

# 5. ПРОБЛЕМА МАНИПУЛЯЦИИ ЧЕРЕЗ НЕФИКСАЦИЮ

## 5.1 Угроза

Участник может попытаться:

- не фиксировать артефакт;
- задерживать фиксацию;
- накапливать скрытый вклад;
- манипулировать моментом распределения долей.

## 5.2 ПРИНЦИП ЗАЩИТЫ

> Вклад существует только с момента фиксации артефакта в реестре.

## 5.3 ЖЁСТКОЕ ПРАВИЛО

Если артефакт не зафиксирован:

- он не существует для системы;
- он не учитывается в распределении;
- он не влияет на состояние.

---

# 6. ОБЯЗАННОСТЬ ФИКСАЦИИ

## 6.1 Правило

Участник, создавший артефакт, обязан:

- зафиксировать его в реестре;
- привязать к состоянию;
- указать свой вклад и вклад других участников.

## 6.2 НАРУШЕНИЕ

Если участник не фиксирует артефакт:

- вклад не засчитывается;
- состояние не может быть завершено через этот артефакт;
- система игнорирует «необъявленный результат».

## 6.3 СМЫСЛ

> Система признаёт только опубликованную и зафиксированную реальность.

---

# 7. ФИКСАЦИЯ СОСТОЯНИЯ

## 7.1 Процесс

1. Создан артефакт.
2. Внесён в реестр.
3. Открыто окно проверки.
4. Нет оспаривания.

## 7.2 РЕЗУЛЬТАТ

> Состояние считается принятым и закрытым.

---

# 8. ВКЛАД УЧАСТНИКОВ

## 8.1 Определение

**Вклад** — участие в создании или завершении артефакта состояния.

## 8.2 Формы вклада

- разработка;
- дизайн;
- тестирование;
- интеграция;
- исправления.

## 8.3 НЕ ЯВЛЯЕТСЯ ВКЛАДОМ

- идеи;
- обсуждения;
- статус;
- присутствие.

---

# 9. РАСПРЕДЕЛЕНИЕ ДОЛЕЙ

## 9.1 Принцип

Каждое состояние имеет долю из:

**60% командного пула.**

## 9.2 Распределение

Происходит только:

- через вклад в артефакты состояния.

---

# 10. МАТЕМАТИКА (ПРИМЕР)

### Участники

- Участник A;
- Участник B;
- Участник C.

### Состояние

**S2**

Пул:

**15%**

### Артефакты

- A → backend;
- B → UI;
- C → тестирование.

### Веса

| Артефакт | Вес |
|----------|----:|
| Backend | 3 |
| UI | 2 |
| Test | 1 |

### Расчёт

Общий вес:

```
3 + 2 + 1 = 6
```

Доли:

- **A** → 50%;
- **B** → 33.3%;
- **C** → 16.7%.

### Итог

Полученные значения переводятся в доли проекта.

---

# 11. ОСПАРИВАНИЕ

## 11.1 Условия

Только через:

- новый артефакт;
- или доказательство ошибки.

## 11.2 Запрет

Не допускаются:

- мнение;
- голосование без доказательства.

## 11.3 Итог

Если ошибка не подтверждена:

> Запись считается окончательной.

---

# 12. ПРИНЦИП СИСТЕМЫ

> Проект существует только как цепочка зафиксированных состояний, где каждое состояние подтверждается артефактом, созданным и зарегистрированным участником, и только эти артефакты формируют распределение долей.

---

# 13. ЗАКЛЮЧЕНИЕ

Хартия устанавливает:

- обязательную фиксацию всех результатов;
- невозможность скрытого вклада;
- связь состояния только с артефактами;
- распределение долей только через доказанный вклад.
